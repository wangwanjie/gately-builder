# Gately Builder

按需定制 [Gately](https://github.com/wangwanjie/gately) 安装包：选择版本、平台、功能模块和界面语言，得到只包含所需功能的安装包，适合存储空间较小的 ARM 设备。

本仓库只存放构建器网页、构建工作流和构建产物。网页上线后地址为 <https://build.gately.cn>。

---

Build a custom [Gately](https://github.com/wangwanjie/gately) package: pick a release, platforms, feature modules and UI languages, and get a package containing only what you need — handy for ARM devices with little storage.

This repository only holds the builder page, the build workflow and the build outputs. The page will be available at <https://build.gately.cn>.
